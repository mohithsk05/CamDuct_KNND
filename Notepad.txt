
## 1. Purchase Entry Calculations

### Fields entered by the user
| Field | Input |
|---|---|
| `qty` | Quantity received (in purchase unit, e.g. Kg's) |
| `rate` | Rate per unit (₹) |
| `basic` | Basic amount (₹) — **auto-filled** as `qty × rate` unless manually overridden |
| `cgst` | CGST tax amount (₹) |
| `sgst` | SGST tax amount (₹) |
| `igst` | IGST tax amount (₹) |
| `trans_as_invoice` | Transport cost as per invoice (₹) |
| `trans_per_unit` | Transport cost per unit (₹) — informational only |

### Auto-calculations (real-time, in the purchase form)

```
Basic (₹) = qty × rate           ← auto-filled when qty or rate changes
                                    (can be overridden manually)

Total (₹) = Basic + CGST + SGST + IGST + Transport (Invoice)
```

> **Note:** If you type into the Basic field manually, it locks and stops being overridden by qty × rate for that session. Reopen the modal to reset.

## 5. Raw Material Master — Auto-Derived Fields

When a material is added via the **Add Material** form (simplified), the system automatically derives:

| Field | Auto Rule |
|---|---|
| `display_conversion` | `1000` if Display Unit = **MT**, else `1` |
| `is_gi_coil` | `1` (true) if Purchase Unit = **Kg's** AND Consume Unit = **Sqmt**, else `0` |
| `conversion_rate` | Defaults to `1` on creation — **must be updated by owner/manager** for Sqmt materials to reflect actual Kg-per-Sqmt weight |

> **Important:** For Sqmt-type materials (e.g. GI Sheet, Aluzinc), the `conversion_rate` (Kg per Sqmt) must be edited after creation by the owner or manager. Until it is set correctly, consumption Kg values will be inaccurate.
